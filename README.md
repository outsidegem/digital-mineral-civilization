# Digital Mineral Civilization (DMC)

Standalone, Termux-first engineering workspace. This repository is intentionally separate from all existing Titan repositories.

## Current status
- Foundation: scaffold only
- Constitution `DM-FOUNDATION-001 v2.2`: proposed; pending Founder ratification
- Current milestone: M1 — Constitutional Core
- No production authority, live wallet operations, token deployment, or financial transactions are implemented or authorized here.

## Initial build

```bash
cargo test --workspace
```

The first executable capability is deterministic policy evaluation. It is a software control, not a complete security boundary: future execution services must enforce decisions at every actual execution/resource boundary.
