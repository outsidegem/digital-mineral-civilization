# Build sequence

1. M1: validate the workspace and policy baseline (`cargo test --workspace`).
2. Review policy cases and threat model before expanding permissions.
3. M2: versioned policy registry and policy fixtures.
4. M3: cryptographic identity, delegation/revocation, and durable audit design.
5. M4: resource governance and execution gateway interfaces.

Do not connect existing Titan repositories, wallets, RPC endpoints, or production services during this bootstrap.
